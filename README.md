# README - Decision Tree with Pen and Paper

Learn how to implement a decision tree, study the math behind it, and build your model. This project requires a basic  
understanding of probability and the simplest math. As a result, use the decision trees you built to make predictions  
for new samples.

## About
Have you ever wondered how machine learning algorithms work from the inside? This project provides a good insight into  
the mechanism behind one of the well-known algorithms – a decision tree. Classification and calculations, let's do it  
ourselves!

## Stages
### Stage 1/7: Concept
Make a simple, intuitive decision tree. Learn how to create simple decision rules.  
### Stage 2/7: Gini Index
Learn about the Gini index and data impurity. Find the Gini index for the provided examples.  
### Stage 3/7: Build a decision tree with the Gini index
Apply the Gini index to find the optimal feature and split the data. Build a simple decision tree by repeating the  
procedure multiple times.
### Stage 4/7: Entropy
Learn about entropy. Find the entropy of the data.
### Stage 5/7: Information gain
Grasp the concept of information gain and find out how to use it for finding the optimal splits of the data.
### Stage 6/7: Build a decision tree with information gain
Build another decision tree using information gain. Predict the unclassified data.
### Stage 7/7: Predict the cases
You've already built two models; it's time to make predictions about the data.
